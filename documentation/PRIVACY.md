# 隐私说明

本说明针对当前维护的 Yuklick FDroid 构建，不代表上游全部发行渠道。

## 设备权限与数据

- 无障碍服务用于执行点击、滑动、系统操作和用户配置的文本输入。
- 屏幕捕获用于图像及文字条件检测；识别由设备上的 OpenCV / ncnn 执行。
- 悬浮窗用于运行控制、配置、示教及调试。
- 场景、条件图片、动作文本和备份可能包含屏幕内容、个人账号或其他敏感信息。导出 ZIP 是普通数据文件，不应视为加密备份。

## 网络

简体中文和拉丁字母识别模型随安装包提供。其他字母表模型按需从 GitHub 官方上游地址下载；网络服务提供方可获得通常的连接信息，例如 IP 地址。模型下载接口不用于上传用户屏幕。

源码仍保留上游 Play Store 变体及相关依赖配置。本项目当前不交付该变体，不将本说明作为其广告、统计或服务条款说明。

## 报告问题

提交截图、日志或场景前先删除账号、消息、位置、设备序列号、个人目录、访问令牌和付款信息。优先使用专门构造的最小测试场景。不要上传签名文件、完整手机日志、原始备份或屏幕录制。

## 仓库发布

公开源码导出排除本机 SDK、缓存、IDE 状态、日志、安装包、签名文件、环境配置和 `.git` 历史。自动扫描只能发现明确模式，不能证明不存在一切敏感内容；维护者需检查生成的文件清单及差异。
